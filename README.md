# Local Business Landing Page - Central Roofing Ghana

## Project Overview
* **Student Name:** Isaac Oboh Yamoah
* **Assigned Industry:** Construction & Roofing Services
* **Business:** Central Roofing - Ghana
* **Target Customers:** Homeowners and commercial property managers looking for durable roofing installation, waterproofing, and repairs.
* **Main Goal:** Provide a clear overview of services, outline the work process, showcase recent projects, and enable customer enquiries via an interactive demo contact form.

## Features
* Six responsive sections: Hero, Services, How We Work, Recent Work, Contact Us, and Footer.
* Interactive JavaScript contact form validation with dynamic success feedback messaging.

## Build Process & Tech Stack
* **Technologies Used:** HTML5, CSS3 (Flexbox/Grid), and Vanilla JavaScript.
* **Version Control:** Initialized local Git repository, managed via PowerShell, and synchronized with GitHub.
